# HANAA SHOP — Team NEXORA

A responsive fashion boutique website concept built from the Instagram screenshot supplied by the client.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `hanaa-shop`).
2. Upload all files and the `assets` folder, preserving the folder structure.
3. Open repository Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)` → Save.
5. Wait for GitHub Pages to publish the site.

## Before going live
- Confirm product names, availability, sizes, prices and delivery details with Hanaa Shop.
- Replace the Instagram contact URL if the client provides another official order channel.
- Replace the six cropped reference photos with original product photos supplied/approved by the shop.
- This is a presentation/catalogue concept. It does not claim live inventory, payment processing or checkout.
